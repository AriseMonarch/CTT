<h1 align="center"> Computer Technician Tools </h1>
<p align="center"> The Open Source Knowledge Base For Fixing, Configuring, Securing, Understanding Technology And Much More...</p>


<p align="left">Its contents consists of: </p>

<p align="left"> Hardware information tools (Tools that help you view the exact hardware specifications of your computer or configure them)
                 Software Diagnostic tools  (they allow you to further inspect crashes and help you troubleshoot more accurately)
                 File recovery tools (like bootable USBs to help with recovery, reparing or unbootable windows without touching the main drive)
                 Botable USBs (Creating a USB that can hold multiple iso. files for multiple Operating Systems)
                 Security Apps (Apps that do more than enough in order to keep you safer)
                 Benchmark Software (Tools that allow you to stress and view the performance in a wide variety of things)
                 Benchmarl Results (Allow you to preview the results of your computer benchmarks)
                 Platforms (Explanations, Guidance and help with troubleshooting on every OS)
                 Commands (Explanation with what commands are, what they do, and for what reason we use them)
                 Android (Help with troubleshooting, repairing, explaining and diagnosing) </p>

<p align="center"> This Will Aim To Be The Main Source Of Troubleshooting And Helping With Whatever Problem You May Have With Technology</p>
